# 🎥 VideoSharingApp

A cross-platform mobile video sharing app built with **React Native** and powered by a **Node.js** backend with **MSSQL** database.

---

## 🚀 Features

- 📱 Mobile app (React Native) for uploading & viewing videos
- ⬆️ Upload short videos
- ❤️ Like & comment on videos
- 🔐 User authentication
- 📊 Video statistics (likes, comments)
- 📦 RESTful API with Node.js + Express
- 🗃️ Store videos in local
---

## 🛠️ Tech Stack

- **Frontend:** React Native (Expo or CLI)
- **Backend:** Node.js, Express.js
- **Database:** Microsoft SQL Server (MSSQL)
- **Others:** REST API, MVC pattern, Git
